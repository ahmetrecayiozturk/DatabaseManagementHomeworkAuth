# SQL Story Game Backend

A backend API for SQL Story Game built with [NestJS](https://nestjs.com/).

## Description

This is a NestJS backend application that provides RESTful APIs for the SQL Story Game.

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Linting

```bash
# lint and fix files
$ npm run lint

# format files
$ npm run format
```

## Build

```bash
# build the application
$ npm run build
```
